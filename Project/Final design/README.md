# System D — final design (Tasks 1 and 2)

The complete woofer-box tuning and crossover design for System D, with the scripts that produce
every number and figure. The write-up is `report/Project_report.tex` (also compiles in Overleaf from
the repo root; PDF next to it).

| | Design |
|---|---|
| Woofer box | one vent, L = 160 mm: f_B 24.6 Hz, f_3 33 Hz, +1.8 dB ripple |
| Digital crossover (MiniDSP) | LR4 at 325 Hz (two Butterworth biquads, Q 0.707), woofer −4.5 dB |
| Midrange low-pass | LP2: 0.82 mH series, 6.8 µF shunt |
| Tweeter high-pass | HP2: 5.6 µF series, 0.22 mH shunt, L-pad 4.7 Ω series / 3.3 Ω shunt |
| Polarity | all + |
| Result (simulated) | on axis 150 Hz–15 kHz within 3.9 dB, 30° within 6.3 dB; amp ch. 2 ≥ 4.4 Ω |

## Folders

```
design/design.json        the design (every value above)
design/xover.py           whole system: MiniDSP biquads, passive ladders loaded by the measured Zi,
                          Lab E responses, Task 1 box; prints the metrics
ltspice/task1/            Task 1: woofer box fitted to the Lab D impedances (box_model.py) and its
                          LTspice circuit Task1_WooferBox.asc
ltspice/System_D_design.asc   Task 2: the full system in LTspice (generated by gen_system.py)
ltspice/units/            each unit alone with its measured Zi + TF
data/                     LTspice data files (Zi, TF, TF30, Box_woof), csv/ for the scripts,
                          dsp/ = coefficients for the MiniDSP (Advanced) and LTspice
figures/                  report figures
app/index.html            Crossover Studio: change any value and see the result in the browser
report/                   Project_report.tex + generated results_*.tex
lab-day/                  Task 3 session: checklist, measurement wrapper + plan (MATLAB), model curves
```

## Rerun

```bash
cd design && python3 xover.py --plots --export        # metrics, figures, dsp/ strings, results_design.tex
cd ltspice/task1 && python3 box_model.py --plots      # driver/vent fit, tuning table, results_task1.tex
cd ltspice/task1 && python3 gen_box_ltspice.py --verify   # writes Task1_WooferBox.asc, runs LTspice, compares
cd ltspice && python3 gen_system.py --verify          # writes System_D_design.asc, runs LTspice, compares
cd app && python3 build_app.py --test
```

The `.asc` files are generated: change `design/design.json` (or the scripts) and rerun, don't edit them
by hand. `--verify` needs LTspice under wine and the Lab A schematic builder in `../../Lab A/LTspice/`.
