# Lab A in LTspice

Ready-to-run schematics for all four parts, generated by `gen_ltspice.py` and
verified by running LTspice 26 headless and comparing with the runthrough numbers
(`python3 gen_ltspice.py --verify`, about three minutes).

`python3 preview_asc.py` draws every schematic to `preview/*.png` (LTspice cannot export a
picture headless) and lints the layout: label on label, label on a symbol, wire through a label.
Run it after changing the generator; all seven sheets should report 0 issues.

Open with `ltspice "<file>.asc"`, press Run. Each `.asc` has a `.plt` with the same
name, so the traces above load by themselves in stacked panes; if a pane looks
empty, click it and press Ctrl+E (zoom to fit). Right-click the y-axis to switch
between dB and linear, and to hide the phase for a cleaner screenshot.

Element names carry the physics: `C_Mmvc` is the mass M_mvc drawn as a capacitor
(mobility analogy), `L_Cmsp` the compliance C_msp drawn as an inductor, `R_Rmsp`
the damper as a resistor of value `1/Rmsp`. All values are `.param`s printed on the
sheet, which is what the quiz asks for ("element values as text").

Things that matter:
- Part 2 sweeps with `.ac dec 2000` because the ladder has Q > 100; 200 points per
  decade clips the peaks by several dB.
- No leak resistor across the volume-velocity source. The first ngspice version had
  100 MΩ there and lost 13 dB of peak height: |Z_in| is 0.3–1.5 GΩ at the peaks.
- Inductors have `Rser=0` (LTspice's hidden default is 1 mΩ); the link inductor keeps
  `Rser=1u` so the three-inductor loop has a DC solution.
- G sources: current flows from the symbol's + pin through the source to its − pin.
  The injector `G_a*` has − on the acoustic node; the reaction `G_m*` is rotated so
  + sits on the velocity node and draws force out of it. Flip one and the resonance
  moves *up* instead of down to 43.7 Hz.
